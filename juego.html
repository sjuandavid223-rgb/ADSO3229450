🧩 Reto 1

¿Qué pseudoclase selecciona al primer hijo? 

.mensajes p:first-child {
    color: cyan;
}

🧩 Reto 2

¿Cuál selecciona el último hijo? 

p:last-child {
    color: magenta;
}

🧩 Reto 3

¿Qué selecciona los elementos pares? 

p:nth-child(even) {
    color: orange;
}

🧩 Reto 4

¿Qué selecciona los elementos impares? 

p:nth-child(odd) {
    color: lime;
}

🧩 Reto 5

¿Qué hace :only-child? 

p:only-child {
    color: purple;
}

🧩 Reto 6

¿Qué hace :only-of-type? 

p:only-of-type {
    color: orange;
}

🧩 Reto 7

¿Qué pseudoclase selecciona un elemento vacío? 

.caja:empty {
    border: 2px solid magenta;
}

🧩 Reto 8

¿Qué pseudoclase detecta un checkbox seleccionado? 

input:checked {
    accent-color: cyan;
}
